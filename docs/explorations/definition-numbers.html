The Definitions page of the word detail view at the new sizes (word 44 pt bold, definitions 28 pt semibold). Each option shows a different way to number definitions. A word with only one definition shows no number in any of them.

A · Hanging numeral

"1." in the definition's own type, in the faintest ink. The text wraps clear of it.

B · In the margin

A small number in the page margin. The text column stays lined up with the word.

C · Small number above

A small 17 pt number sitting above each definition, like a quiet label.

D · Badge

The number in a small grey circle, the app's control fill, beside the first line.

E · Dark numeral

The number in the darkest ink, the same as the word, running straight into the grey definition.

F · Ruled

A small margin number, with thin lines dividing the definitions.

G · First leads

The main definition stays at 28 pt; the others step down to 22 pt. All three are numbered.

H · Big ghost numeral

A 44 pt numeral at 10% ink behind the start of each definition, in a magazine style.
